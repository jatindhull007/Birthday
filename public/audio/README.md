# Audio Assets Directory

This folder is configured for custom background audio tracks and sound effects.

### How to use custom audio files:
1. Drop your suspense/cyber loop as `public/audio/suspense_loop.mp3`
2. Drop your emotional celebration track as `public/audio/celebration_theme.mp3`
3. Optional SFX:
   - `public/audio/sfx_typewriter.mp3`
   - `public/audio/sfx_buzzer.mp3`
   - `public/audio/sfx_success.mp3`
   - `public/audio/sfx_vault_unlock.mp3`

> [!NOTE]
> The app is already equipped with a high-fidelity procedural Web Audio synthesizer engine in `src/services/soundService.js` that works out-of-the-box with zero lag, instant feedback, and zero external network dependency!
